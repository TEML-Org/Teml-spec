What the board can't show yet

Everything above is drawn from the TEML file alone. These parts of a full hotel Event Model have no place in teml.org/v-alpha-001, so they are missing from the board:

  1. The "browse rooms" step. A view-only slice, where the guest sees Room Availability before booking. Every TEML slice needs an event.
  2. Who uses each screen. Guest, manager, front desk and housekeeping should be separate lanes at the top. TEML has no actors, so all screens share one lane.
  3. Which screen shows which read model. For example, Room Search shows Room Availability.
  4. The payment provider's "payment succeeded" event. It can't be declared, so Payment Listener appears with nothing triggering it.
  5. Which read model an automation works from. Payment Requester's to-do list is Payments To Request.
